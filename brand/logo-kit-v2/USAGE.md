# Joshua Dolor — Period Core

**Idea:** A solid disc with a geometric **J** punched through as negative space — the period/core of the brand, built to replace a WebGL sphere.

## Colours
| Role | HEX | Use |
|---|---|---|
| Primary | `#3b82f6` | Default mark on dark UI |
| Secondary | `#f5b942` | Accent / contact pulse |
| Ink | `#000000` | One-colour print |
| Paper | `#ffffff` | Reversed on dark |
| Dark tile | `#0a0a0a` | App icon / favicon field |

## Masters
- `period-core.svg` — black master (evenodd holes)
- `period-core-small.svg` — thickened cut for ≤32 px
- `period-core-blue.svg` / `period-core-amber.svg` — brand colour
- `period-core-horizontal.svg` / `period-core-stacked.svg` — lockups
- `period-core-*-black|white|mono-*.svg` — export variants
- Web set: `favicon.ico`, `favicon.svg`, `apple-touch-icon.png`, `icon-192/512.png`

## Clear space
Keep clear space around the mark equal to **¼ of the disc diameter** (the top bar of the J).

## Minimum size
- Digital symbol: **24 px**
- Favicon / tab: use `period-core-small` / exported favicon set
- Print: **12 mm** height

## Misuse
Do not fill the J cut, stretch the disc, add shadows/gradients to the mark, or place type inside the cutout.

## Type
Lockups assume **IBM Plex Sans** (or Helvetica Neue) at semibold. Site UI continues with Fraunces + Source Sans 3; the mark itself is outlined paths — no live text in the symbol.
